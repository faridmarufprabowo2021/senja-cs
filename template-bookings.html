📄 Template Import Booking - Senja CS

✅ **File sudah siap!** Klik tombol "Download Template CSV" di bawah untuk mendapatkan file ready-to-use.
⚠️ **PENTING**: File harus dalam format CSV (comma-separated values), bukan gambar atau format lain!

📋 Format yang Diperlukan

Kolom Contoh Wajib? Keterangan
Layanan Potong Rambut ✅ Ya Nama layanan atau booking
Jadwal Booking 2026-08-15T14:00:00Z ✅ Ya Format ISO 8601 dengan timezone UTC
Nama Pelanggan Budi Santoso ✅ Ya Nama lengkap pelanggan
Nomor WA +62812345678 ✅ Ya Mulai dengan +62, tanpa spasi/titik
Catatan Gerigi ❌ Tidak Catatan tambahan (boleh kosong)
Status pending ✅ Ya "pending" atau "confirmed"

📝 Contoh Data CSV

Layanan,Jadwal Booking,Nama Pelanggan,Nomor WA,Catatan,Status Potong Rambut,Budi Santoso,+62812345678,2026-08-15T14:00:00Z,Gerigi,pending Facial SPA,Siti Aminah,+62812345679,2026-08-16T10:00:00Z,,confirmed Jasa Service AC,Pak Joko,+6281334455667,2026-08-17T09:00:00Z,Mohon pagi hari,pending

🔧 Cara Membuat File CSV

  1. Metode 1 - Excel/Google Sheets (Recommended):
    • Buka Microsoft Excel atau Google Sheets
    • Salin data dari tabel di atas sebagai contoh
    • Klik File > Save As / Download
    • Pilih format CSV (Comma delimited)
    • Simpan dengan nama template_booking.csv
  2. Metode 2 - Text Editor:
    • Buka Notepad atau text editor apa saja
    • Paste contoh data di atas
    • Simpan dengan Save as type: All Files
    • Namai file: template_booking.csv
    • Ensure encoding is UTF-8

⚠️ Aturan Penting

  • ✅ Gunakan koma (,) sebagai pemisah antar kolom
  • ✅ Nomor WA harus dimulai dengan +62
  • ✅ Format tanggal harus ISO 8601: YYYY-MM-DDTHH:MM:SSZ
  • ✅ Status hanya boleh: pending atau confirmed
  • ✅ Jika ada nilai mengandung koma, gunakan tanda kutip: "Layanan dengan Spasi"
  • ❌ JANGAN upload file gambar (.png, .jpg, dll)
  • ❌ JANGAN upload file Excel (.xlsx) langsung

🎯 Cara Upload ke Aplikasi

  1. Login ke dashboard Senja CS
  2. Buka halaman Booking
  3. Klik tombol Import CSV
  4. Pilih file template_booking.csv yang sudah disiapkan
  5. Tunggu proses import selesai
  6. Lihat hasilnya di daftar booking
💡 Tip: Setelah download, buka file dengan Notepad untuk memastikan formatnya benar sebelum upload ke aplikasi.
